Enhancing Bitnami Helm Charts Security: A Kubescape Case Study Introduction CVEs get all the press when it comes to secure software supply chain, and for good reason: vulnerabilities in open source code cost the global economy billions of dollars per year. However, even the most secure applications with the best supply chain provenance can be accidentally misconfigured in such a way that leaves insidious security holes lurking in your environment. Much of the value that Bitnami adds in packaging open source software is in the configuration.
